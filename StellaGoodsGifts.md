# 1. Scope

This document records the pillow-cover workflow confirmed during the 2026-09-21 discussion.

It covers:

- The standard 8-image Etsy pillow-cover template
- Rules for generating each image
- Rules for product-truth images vs lifestyle images
- Product-accuracy requirements
- Fabric / print / embroidery detail rules
- Construction-detail rules
- Size-guide rules
- Shop-the-Look rules
- Etsy listing template
- Product Facts / Listing Copy separation
- TBD / no-hallucination rules

The purpose is to make future StellaGoodsGifts pillow-cover launches consistent, fast, and easy to call again.

# 2. Product Facts = Source of Truth

Product Facts and marketing copy must be stored and treated separately.

## Product Facts may include

- Product type
- Material / fiber composition
- Fabric type
- Technique: printed / embroidered / jacquard / woven / etc.
- Main color
- Secondary colors
- Pattern / motif
- Shape
- Size(s)
- Closure
- Piping / edge construction
- Tassels / fringe
- Back design
- Sales unit
- Whether insert is included
- Insert material only if insert is actually sold
- Care instructions
- Custom-size availability
- Other confirmed specifications

## AI must not guess

Never infer the following only from an image:

- Material composition
- Exact dimensions
- GSM / fabric weight
- Care method
- Insert inclusion
- Insert filling
- Durability
- Machine washability
- Fade resistance
- Handmade status
- Exact production method
- Custom-size availability

If the information has not been confirmed, write:

**TBD**

Do not reuse dimensions, care instructions, or insert information from another product just because the products look similar.

# 3. Standard Pillow Cover 8-Image Template

## Critical output rule

The numbers below are **internal workflow positions only**.

Final Etsy images must:

- be **8 separate image files**
- preferably use **1:1 square format**
- NOT be combined into an 8-panel collage
- NOT contain internal numbering such as 01 / 02 / 03
- NOT contain template labels unless the image itself is intentionally an information graphic
- NOT repeatedly generate the same lifestyle scene for different functional positions

The template defines **8 different functional image types**.

---

## IMAGE 01 — HERO

### Purpose

Create the first-click image.

### Requirements

- Lifestyle scene
- Pillow is the main visual subject
- Medium-close framing
- Product should occupy roughly 55–70% of visual attention
- Pattern must remain readable at Etsy thumbnail size
- Background is calm and secondary
- Soft natural daylight
- Product proportions must remain realistic
- No text
- No internal numbering
- No AI watermark

### Styling rule

**Colorful / high-pattern pillow = quiet room.**

Recommended surroundings:

- Cream / ivory sofa
- Warm-white wall
- Natural wood
- Oatmeal / beige textiles
- Olive, dusty rose, ivory, or muted green accents where appropriate
- Minimal greenery
- Minimal props

Avoid:

- Competing wallpaper
- Too many colorful accessories
- Busy decorative styling
- Luxury-hotel look
- Strong cinematic lighting
- Overly artificial CGI appearance

---

## IMAGE 02 — FRONT VIEW / PRODUCT FRONT

### Purpose

Show exactly what the customer is buying.

### Requirements

- Full front-facing pillow
- Entire product visible
- All corners visible
- Tassels visible if the real product has them
- Straight or nearly straight view
- Plain warm-white / off-white / pale neutral background
- Soft grounding shadow
- No sofa
- No room
- No other pillows
- No decorative props
- No text
- No numbering

### Preferred execution

This is a **product-truth image**.

Whenever the original source photo is good enough, prefer:

- remove background
- crop
- reframe
- straighten
- improve composition
- preserve product

Do NOT ask AI to redesign the pillow.

---

## IMAGE 03 — FABRIC / PRINT / EMBROIDERY DETAIL

### Purpose

Show actual textile quality and motif detail.

### Requirements

- Macro / extreme close-up
- Do NOT show the complete pillow
- Do NOT make it another lifestyle scene
- No sofa
- No bedroom
- No full-product composition
- Focus on actual fabric surface

Depending on the product, show:

### Printed Velvet
- velvet nap
- print sharpness
- color transitions
- line detail
- surface texture

### Embroidered Fabric
- actual stitch appearance
- thread thickness
- embroidery edge
- fabric weave

### Jacquard
- woven structure
- thread pattern
- actual texture

### Linen / Cotton
- real weave
- thread texture
- printed or embroidered motif relationship to the base fabric

### Critical rule

If the source detail photo is clear, prefer:

- crop
- rotate
- reframe
- adjust visual direction

Do not regenerate textile texture unless necessary.

Never convert:

- printed pattern → embroidery
- flat embroidery → 3D embroidery
- ordinary fabric → luxury raised textile

---

## IMAGE 04 — SIDE VIEW / PRODUCT DETAIL

### Purpose

Show pillow depth, edge construction, drape, side profile, and tassel relationship.

### Requirements

- Close or medium-close product view
- Side / 3/4 profile
- Clearly show thickness
- Show piping / edge construction if present
- Show corner tassels if present
- Keep original product proportions
- Product-only or minimal studio setting preferred
- No room-wide lifestyle scene
- No text / numbering

This image should answer:

> What does the product look like from the side?

---

## IMAGE 05 — CONSTRUCTION DETAIL

### Purpose

Show how the pillow cover is made.

### Possible details

Only show features actually present:

- Hidden zipper
- Piping
- Tassel attachment
- Fringe
- Seam
- Corner construction
- Brand label
- Back fabric
- Envelope closure

### Recommended format

A clean detail image may show several close-up construction areas in one image if needed.

However:

- It must remain a product-detail image
- Do not turn it into another full-room lifestyle shot
- Do not invent a closure or label
- Do not change tassel shape / color
- Do not add nonexistent stitching

---

## IMAGE 06 — SECOND ROOM / IN A BEDROOM

### Purpose

Show the same product in a second real-life context.

### Rule

This scene must be visibly different from IMAGE 01.

Example:

IMAGE 01:
- Living room sofa

IMAGE 06:
- Bedroom
- Reading nook
- Window bench
- Bed layering

### Bedroom direction

Recommended:

- Warm-white wall
- Natural wood / woven headboard
- Ivory bedding
- Olive / dusty rose / oatmeal accents
- Soft daylight
- Minimal bedside styling

Product remains the main focus.

No text or numbering.

---

## IMAGE 07 — SIZE GUIDE

### Purpose

Make dimensions immediately understandable.

### Core layout

Use the confirmed template style:

- Clean light / cream background
- Front-facing product centered
- Horizontal width measurement line
- Vertical height measurement line
- Optional title: **Size Guide**
- Minimal text
- Large, readable dimensions
- Keep the real product pattern visible

### Important rule

Do NOT guess a size.

Only use dimensions confirmed for the current SKU.

Do NOT copy:

- 45 × 45 cm
- 50 × 50 cm
- 60 × 60 cm
- 50 × 30 cm

from another product unless the current product actually uses those dimensions.

If size is not confirmed:

**TBD**

Do not fabricate a size guide.

### Units

Where helpful:

- centimeters
- inches

Example:

`50 × 30 cm / approx. 20 × 12 in`

Only when confirmed.

---

## IMAGE 08 — SHOP THE LOOK / STYLING

### Purpose

Help the buyer understand how to coordinate the statement pillow.

For pillow covers, IMAGE 08 is usually:

**SHOP THE LOOK**

It is NOT automatically a curtain-style Lining Options image.

### Recommended styling

Main product +
- 1–2 coordinating plain pillows
- neutral throw
- compatible room accents

Examples:

- Olive Green Pillow
- Dusty Rose Pillow
- Ivory Textured Pillow

### Important rule

If coordinated StellaGoodsGifts SKUs actually exist, they may be shown.

If no coordinated SKU exists yet:

- show generic styling inspiration
- do not label nonexistent products as available items
- do not invent matching curtains / table runners / other SKUs

# 4. Which Images Should Use AI?

The template is divided into two groups.

## Product-truth images

Prefer source-image editing / crop / reframe:

- IMAGE 02 — FRONT VIEW
- IMAGE 03 — FABRIC DETAIL
- IMAGE 04 — SIDE VIEW
- IMAGE 05 — CONSTRUCTION DETAIL

These images explain the actual product.

AI should not redesign them.

## Lifestyle / presentation images

AI scene generation is more appropriate for:

- IMAGE 01 — HERO
- IMAGE 06 — SECOND ROOM
- IMAGE 08 — SHOP THE LOOK

## Information image

- IMAGE 07 — SIZE GUIDE

Use confirmed dimensions only.

# 5. Global Product Accuracy Rules

For every generated image, preserve as closely as possible:

- base color
- motif shape
- motif orientation
- motif placement
- pattern scale
- fabric texture
- printed vs embroidered character
- piping
- tassels
- fringe
- zipper / closure
- product shape
- square vs rectangular proportions
- brand label where actually present

AI may primarily change:

- scene
- background
- composition
- light
- camera distance
- visual direction

AI should NOT change:

- product facts
- pattern identity
- animal type / central motif
- fabric technique
- number of tassels
- tassel color
- edge color
- product aspect ratio

Beautiful but inaccurate images are rejected.

# 7. Lessons From Image Generation

The following execution rules were confirmed after testing.

## Do not repeatedly generate the template itself

The user may provide or approve an 8-panel visual template as a reference.

That means:

> Use the 8 positions as instructions for 8 separate images.

It does NOT mean:

> Generate another 8-panel collage.

## Do not let every prompt fall back to a living-room image

If the required position is:

- Front View
- Fabric Detail
- Side View
- Construction

then explicitly prohibit:

- sofa
- living room
- bedroom
- whole-room scene
- complete pillow when inappropriate

## Do not put workflow numbers on final images

Numbers such as 01 / 02 / 03 are for internal organization only.

## Do not invent measurements

The size guide is factual content, not decoration.

# 12. Variations Template

Only create a variation when the buyer actually has a choice.

## Size

If one size only:

Do not create an unnecessary variation.

State the size directly in the listing.

If multiple sizes exist:

**Variation: Size**

- [Size A]
- [Size B]
- [Size C]

## Insert

Only create:

- Cover Only
- Cover + Insert

if both are actually sold.

Do not create an insert variation when the listing only sells the cover.

Care instructions must come from confirmed supplier / production information.

- Bleach safe

# 18. Reusable Command for Future Products

When a new pillow product is provided, execute:

1. Read source product images.
2. Extract only visually verifiable product features.
3. Ask / use supplied Product Facts for material, dimensions, care, insert, etc.
4. Mark unknown facts as TBD.
5. Generate images according to the fixed 8-image functional template.
6. Do not combine the 8 images into a collage.
7. Do not print workflow numbers on final images.
8. Use source editing for images 02–05 whenever possible.
9. Use AI scenes mainly for images 01, 06 and 08.
10. Generate IMAGE 07 only from confirmed dimensions.
11. Check product accuracy before approval.
12. Generate Etsy listing copy only from confirmed Product Facts.

---

# 19. Master Rule

> **The template is a workflow, not a collage.**
>
> **Product-truth images explain the actual product. Lifestyle images sell the feeling.**
>
> **Never sacrifice product accuracy for a prettier image.**
